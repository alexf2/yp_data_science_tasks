Процесс подготовки данных для обучения модели логистической регрессии по шагам:

1. Переименовать поле geo_location --> geo_id.

2. Удалить колонку user_id.

3. Преобразуем типы признаков в типы numpy, которые нужны и удобны для обучения линейных моделей:
	CAT_VARS: df['col'].astype("category") - в последующих шагах будет OneHot и Target encoding и удаление исходной колонки.
	CONTINIOUS_VARS: np.float64
	BINARY_VARS: np.int8

4. В CONTINIOUS_VARS отрицательные значения сбросить в NA.

5. Заполняем пропуски NA в CAT_VARS и неявный пропуск 'none' в subscription_status категорией unknown.

6. Заполнить пропущенные парные поля на основе связанного значения, если пропущено только одно поле из пары:
	пропущен order_frequency_week: order_frequency_week = order_frequency_month / 4.333
	пропущен order_frequency_month: order_frequency_month = order_frequency_week * 4.33
	пропущен avg_order_value: avg_order_value = median_order_value
	пропущен median_order_value: median_order_value = avg_order_value
	пропущен total_spent_last_month: total_spent_last_month = total_spent_last_week * 4.33
	пропущен total_spent_last_week: total_spent_last_week = total_spent_last_month / 4.33 


7. Заменить следующие поля на новые, старые удалить (order_frequency_month, order_frequency_week, avg_order_value, median_order_value, total_spent_last_month, total_spent_last_week):
	order_frequency_combo = (order_frequency_month + order_frequency_week * 4.33) / 2 

	order_value_stability = median_order_value / (avg_order_value + 0.01)
	weekly_spent_share = total_spent_last_week / (total_spent_last_month + 0.01).

 
8. Пропуски в app_crashes_last_month заполнить нулём с добавлением add_indicator.
9. Пропуски в days_since_last_order, days_since_last_promo заполнить 999 с добавлением add_indicator.
10. Заполнить пропуски во всех полях CONTINIOUS_VARS за вычетом days_since_last_order, days_since_last_promo, app_crashes_last_month через IterativeImputer с RandomForestRegressor / или RandomizedSearchCV - быстрее. 
Лучше IterativeImputer(max_iter=10, random_state=SEED)  # дефолтный BayesianRidge.
Учесть, что в шаге 7 часть полей CONTINIOUS_VARS заменены.

11. BINARY_VARS заполнить общей модой по каждой колонке.

12. Выполнить clip по процентилям 0.01, 0.99 CONTINIOUS_VARS кроме review_rating_last_10, review_rating_last_1, app_crashes_last_month, discount_usage_rate.

13. Заменить часть переменных CONTINIOUS_VARS на логарифмы. Исходную переменную удаляем, новую добавляем с суффиксом _log. Переменные такие: days_since_last_order, order_frequency_combo, order_value_stability, weekly_spent_share, app_opens_per_week, days_since_last_promo.

14. Закодировать CAT_VARS за исключением geo_id при помощи OneHotEncoder с drop='first'. Исходные колонки удалить. geo_id закодировать через TargetEncoder.

15. Применить нормализацию и масштабирование.
	StandardScaler: order_frequency_combo_log, order_value_stability_log, weekly_spent_share_log, review_rating_last_10, review_rating_last_1, app_crashes_last_month, geo_id, app_opens_per_week_log.
	RobustScaler: days_since_last_order_log, days_since_last_promo_log.
	MinMaxScaler диапазон 0, 1: discount_usage_rate.
